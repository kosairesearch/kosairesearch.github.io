01

리포트 개요

결제 성장과 이익 변동성이 공존하는 구간

쿠콘은 2026년 3분기 매출이 2024년 2분기 이후 최대 규모를 회복했지만 같은 분기 지배주주 순손실 9억원으로 적자 전환해, 본업 성장과 분기 순이익 변동이 함께 드러나는 국면이다.

  1. 1

    2025년 연간 매출은 695억원으로 전년 대비 4.9% 감소했지만 영업이익은 189억원으로 13.7% 늘었고 영업이익률은 27.2%로 회복됐다.

  2. 2

    2026년 3분기 매출은 203억원으로 전년 동기 대비 16.9% 늘었고, 페이먼트 부문 매출이 분기 기준 처음으로 100억원을 넘었다.

  3. 3

    2025년 지배주주 순이익은 215억원으로 2023년부터 3년 연속 증가했으나, 2026년 3분기에는 순손실 9억원으로 적자 전환했다.

  4. 4

    부채비율은 2022년 40.8%에서 2025년 83.9%로 매년 올랐고, 2025년 영업활동 현금흐름은 450억원으로 지배주주 순이익을 웃돌았다.

  5. 5

    MCP 기반 데이터 API 확대, 스테이블코인 결제, 전 분야 마이데이터 등 신사업은 4분기부터 본격화된다고 회사가 밝혔으나 매출 기여는 아직 부문별 공시로 확인해야 한다.

02

사업 구조

쿠콘은 금융 데이터 중계와 결제 인프라를 두 축으로 삼는 비즈니스 데이터 플랫폼 기업이다. 사업은 데이터 부문과 페이먼트 부문으로 나뉘며, 2026년 3분기 발표 기준 데이터 부문 매출은 96.1억원, 페이먼트 부문 매출은 106.6억원이었다.

두 부문의 매출은 전년 동기 대비 각각 12.3%, 21.4% 늘었다. 데이터 부문은 금융 마이데이터 구축 프로젝트 매출이 반영되며 외형을 키웠고, 시세정보 API와 보험설계사 자격 검증 API 등으로 상품군을 넓히고 있다.

페이먼트 부문은 빅테크 기업과 대형 전자지급결제대행(PG)사의 거래량 증가와 신규 고객사 확보가 맞물리며 분기 매출 100억원을 처음 넘어섰다. 고객 기반은 실명 확인 가상계좌와 eKYC·AML 같은 레그테크 패키지 공급으로도 넓어지고 있다.

부문별 수익성은 차이가 있는데, 2026년 1분기 기준 데이터 부문 영업이익률은 32.5%, 페이먼트 부문은 23.6%였다.

2026년 3분기에는 데이터 부문 영업이익이 구축형 프로젝트 비중 확대에 따른 매출 구성 변화로 전년 동기 대비 9.6% 줄어 24억원이었고, 페이먼트 부문 영업이익은 27.1억원으로 26.7% 늘었다.

경쟁 측면에서 회사는 수수료 기반 중계 구조와 200만 QR 가맹점, 10만 프랜차이즈, 4만 ATM 규모의 결제 접점을 강점으로 내세운다. 금융 데이터와 결제 인증 영역에는 여러 사업자가 있어, 부문별 공시 수치만으로는 시장점유율을 산정하기 어렵다.

04

실적 분석

연간 매출은 2022년 645억원에서 2023년 684억원(전년 대비 6.0% 증가), 2024년 730억원(전년 대비 6.8% 증가)으로 늘었다가 2025년 695억원(전년 대비 4.9% 감소)으로 줄었다. 2022~2025년 중 가장 큰 해는 2024년이고 가장 작은 해는 2022년이다.

영업이익은 2022년 200억원에서 2023년 166억원(전년 대비 17.2% 감소)으로 줄었고, 2024년 166억원(전년 대비 변동 없음)을 거쳐 2025년 189억원(전년 대비 13.7% 증가)으로 회복했다.

영업이익률은 2022년 31.0%, 2023년 24.3%, 2024년 22.7%로 낮아진 뒤 2025년 27.2%로 올랐으며, 매출이 줄어든 2025년에 이익률이 회복된 점이 이 기간의 특징이다.

지배주주 순이익은 2022년 36.5억원에서 2023년 71.7억원(전년 대비 96.4% 증가), 2024년 158억원(전년 대비 119.9% 증가), 2025년 215억원(전년 대비 36.2% 증가)으로 2023년부터 2025년까지 3년 연속 증가했다.

영업이익의 증감과 비교하면 순이익 증가 폭이 훨씬 커서, 그 차이는 영업이익 밖 항목에서 나왔을 가능성이 있으므로 정기보고서 손익계산서와 주석에서 구성을 확인할 대상이다.

분기 매출은 2025년 3분기 173억원, 4분기 181억원(전 분기 대비 4.3% 증가), 2026년 1분기 160억원(전 분기 대비 11.5% 감소), 2분기 180억원(전 분기 대비 12.2% 증가), 3분기 203억원(전 분기 대비 12.9% 증가)으로 2026년 2분기부터 2개 분기 연속 늘었다.

1분기 매출 감소의 배경으로 회사는 금융권 대출 규제에 따른 거래량 감소를 들었다. 영업이익은 2025년 3분기 47.9억원, 4분기 50.1억원, 2026년 1분기 44.7억원, 2분기 49.6억원, 3분기 51.1억원으로 5개 분기 동안 44.7억~51.1억원 범위에 머물렀다.

반면 지배주주 순이익은 2025년 3분기 5.8억원, 4분기 7.8억원에서 2026년 1분기 74.3억원, 2분기 132억원으로 늘었다가 3분기 순손실 9억원으로 적자 전환했다. 최근 네 개 분기(2025년 4분기~2026년 3분기) 지배주주 순이익 합계는 205억원이다.

영업활동 현금흐름은 2022년 102억원, 2023년 296억원, 2024년 525억원, 2025년 450억원으로, 2025년에는 지배주주 순이익 215억원을 웃돌았다.

05

산업 분석

쿠콘의 사업은 금융 데이터 연계와 전자결제 거래량이라는 두 전방 수요에 걸쳐 있다. 데이터 부문은 금융 마이데이터 구축 프로젝트와 금융권 API 수요에 따라 매출이 움직이며, 2026년 1분기에는 계절적 비수기와 금융권 대출 규제가 매출 감소 요인으로 제시됐다.

페이먼트 부문은 빅테크 기업과 대형 PG사의 결제 거래량에 연동되어 있어, 2026년 3분기에는 거래량 확대와 신규 고객사 확보가 매출 증가를 이끌었다. 수수료 기반 구조라서 거래량 변동과 정책 변수가 곧바로 매출에 반영되는 것이 업황의 특징이다.

AI 에이전트가 외부 데이터를 직접 호출하는 구조가 확산되면 데이터 API 수요가 늘 수 있다는 것이 회사의 전략 방향이다. 결제 영역에서는 스테이블코인 결제와 정산이 새로운 수요로 거론되며, 관련 제도 정비 일정이 사업화 속도를 좌우하는 변수로 제시됐다.

경쟁 구도는 금융 데이터 중계와 본인확인·결제 인증 영역의 사업자들이 겹치는 구조이며, 같은 IT·소프트웨어 업종의 NICE평가정보, 다우기술, 안랩 등이 비교 대상이 된다. 다만 이들 기업과 매출 규모나 수익성을 수치로 견줘 보려면 각 사 정기보고서를 함께 봐야 한다.

06

전망

회사가 제시한 연간 매출 성장률 목표는 10%이며, 2026년 3분기 전사 매출 증가율 16.9%는 이를 웃돌았다(3분기 발표 기준).

회사는 2026년 4분기부터 AI 에이전트가 데이터를 직접 호출할 수 있도록 하는 MCP 기반 데이터 API 상품을 100여 종으로 늘리고 전 분야 마이데이터 사업을 본격 추진한다고 밝혔다.

페이먼트 부문에서는 모바일 결제 인프라 KSQR의 적용 범위를 넓히고, 관련 제도 정비에 맞춰 스테이블코인 결제·충전·출금 서비스 상용화를 추진한다.

2026년 5월 1분기 발표에서 회사는 알리페이, 위챗페이, 유니온페이 등 글로벌 결제사와의 협업을 늘리고 글로벌 스테이블코인 결제 사업화에 속도를 내겠다고 밝혔다.

2026년 11월 6일에는 블록체인 인프라 기업 DSRV와 온체인 금융데이터 API 및 AI 에이전트 결제 분야 업무협약을 맺었고, 스테이블코인 결제·정산 데이터 제공과 API 이용대금 자동 결제 기술을 공동 검증할 예정이다.

2026년 11월 9일에는 결제 전 카드 명의 확인 서비스 출시 소식도 알려졌다. 경영진은 향후 2~3년 내 글로벌 결제 사업을 전략 핵심 사업으로 키우고 AI 기반 데이터 기업으로 전환하겠다는 목표를 제시했다.

1분기 발표 당시 2분기 이후 회복이 전망됐고 실제로 2분기 매출은 180억원으로 전 분기 대비 12.2% 늘었다. 다음 확인 지점은 신사업의 매출이 부문별 공시에서 어떤 규모로 잡히는지와 영업이익률이 데이터 부문에서 회복되는지다.

강세 요인

페이먼트 거래량 확대

페이먼트 부문 3분기 매출은 106.6억원으로 전년 동기 대비 21.4% 늘었고, 분기 매출이 처음으로 100억원을 넘었다. 빅테크 기업과 대형 PG사의 거래량 증가와 신규 고객사 확보가 함께 작용한 결과로 발표됐다. 페이먼트 부문 영업이익률은 25.4%로 1.0%p 올라 외형 성장과 수익성 개선이 동시에 나타났다.

데이터 상품군과 마이데이터

데이터 부문은 금융 마이데이터 구축 프로젝트 매출이 반영되며 3분기 매출 96.1억원, 전년 동기 대비 12.3% 증가를 기록했다. 회사는 AI 에이전트가 데이터를 직접 호출하는 MCP 기반 API 상품을 100여 종으로 늘리고 전 분야 마이데이터 사업을 추진하겠다고 밝혔다. 기존 금융 데이터 수요 위에 AI 관련 데이터 수요가 더해질 수 있다는 점이 강세 근거로 거론된다.

이익 회복과 현금 창출

연간 영업이익은 2025년 189억원으로 전년 대비 13.7% 늘었고, 영업이익률은 2024년 22.7%에서 27.2%로 회복됐다. 2025년 영업활동 현금흐름은 450억원으로 지배주주 순이익 215억원을 웃돌았다. 2026년 3분기 전사 매출 증가율 16.9%는 회사가 제시한 연간 매출 성장률 목표 10%를 넘었다.

09

약세 요인

분기 순이익 변동성

2026년 3분기 지배주주 순이익은 순손실 9억원으로 적자 전환했다. 같은 해 1분기 74.3억원, 2분기 132억원이던 것과 비교하면 분기 간 편차가 매우 크다. 영업이익이 3분기 51.1억원으로 흑자를 유지한 만큼, 영업이익 밖 항목의 영향을 확인해야 하는 상황이다.

데이터 부문 이익 감소

데이터 부문 3분기 영업이익은 24억원으로 전년 동기 대비 9.6% 줄었다. 구축형 프로젝트 비중 확대에 따른 매출 구성 변화가 원인으로 설명됐다. 부문 영업이익률은 1분기 32.5%에서 3분기 25.0%로 낮아져, 구축형 프로젝트가 늘수록 수익성이 희석될 가능성이 있다.

재무 레버리지 상승과 규제

부채비율은 2022년 40.8%에서 2025년 83.9%로 매년 올랐고, 2025년 말 부채총계는 1,430억원이다. 2026년 1분기에는 금융권 대출 규제로 거래량이 줄어 매출이 전년 동기 대비 7.5% 감소했다. 정책 변수에 따라 거래량이 흔들릴 수 있다는 점이 약세 요인이다.

10

리스크 요인

정책·규제

금융권 대출 규제와 마이데이터 관련 제도가 거래량과 사업 범위를 바꿀 수 있다. 2026년 1분기에는 금융권 대출 규제 영향으로 거래량이 일부 줄었다고 회사가 설명했다. 스테이블코인 결제의 상용화 시점도 제도 정비 일정에 맞춰지므로 외부 변수의 영향이 크다.

신사업 실행

MCP 기반 데이터 API, 스테이블코인 결제, 글로벌 결제 협업은 아직 매출 규모가 부문별 공시로 구분되지 않는 영역이다. 알리페이·위챗페이 등 해외 결제사와의 협업과 에이전틱 AI 재단 가입 추진은 계획 단계에 가깝다. 초기 투자 부담과 수익화 지연이 이익률을 낮출 수 있다.

재무·이익 변동

부채비율 상승이 이어지면 금리와 차입 조건 변화가 이익에 부담이 될 수 있다. 지배주주 순이익이 분기마다 크게 움직여 실적 예측 가능성이 낮다. 2025년 말 기준 자본총계 1,705억원 대비 부채총계 1,430억원 규모가 재무 여력을 좌우한다.

다음 체크포인트

  1. 2026년 4분기 (2026년 10~12월)

    MCP 기반 데이터 API 100여 종 확대와 전 분야 마이데이터 사업이 4분기 매출로 이어지는지 확인한다. 데이터 부문 영업이익률이 3분기 25.0%에서 1분기 수준으로 회복되는지도 함께 본다.

종합 의견

쿠콘은 2025년 매출이 줄었지만 영업이익이 늘고 지배주주 순이익이 215억원으로 3년 연속 증가한 기업이다. 2026년에는 페이먼트 부문이 분기 매출 100억원을 처음 넘는 등 외형 회복이 뚜렷했고, 3분기 전사 매출 증가율 16.9%는 회사가 제시한 연간 목표 10%를 웃돌았다.

반면 같은 3분기에 지배주주 순손실 9억원으로 적자 전환해 분기 순이익의 변동성이 가장 큰 숙제로 드러났다. 데이터 부문의 구축형 프로젝트 비중 확대는 매출을 늘렸지만 부문 영업이익을 줄였고, 부채비율은 2022년 40.8%에서 2025년 83.9%로 올랐다.

MCP 기반 데이터 API, 스테이블코인 결제, 글로벌 결제 협업은 4분기부터 본격화되지만 매출 기여는 정기보고서에서 확인해야 한다. 강세 요인은 결제 거래량과 데이터 상품군 확대, 현금창출력이고, 약세 요인은 순이익 변동과 금융 규제, 재무 레버리지다.

이 리포트는 투자의견이나 목표주가를 제시하지 않으며, 다음 확인 지점은 2026년 사업보고서의 연간 영업이익률과 부채비율, 2027년 1분기 분기보고서의 지배주주 순이익이다.
