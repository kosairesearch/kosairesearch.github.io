01

리포트 개요

API 사용량 급증과 적자 지속 사이

타입캐스트 API 사용량은 크게 늘었으나 2026년 3분기 누적 공시 기준 매출은 제자리이고 적자 폭은 확대됐다.

  1. 1

    2026년 3분기 누적 매출액 29.1억원(전년 같은 기간 대비 0.4% 감소), 영업손실 18억원으로 적자가 이어졌다.

  2. 2

    타입캐스트 API 유료 구독자는 2026년 9월 말 기준 전년 동월 대비 152배로 늘었으나 API 매출 절대 규모는 공개되지 않았다.

  3. 3

    2026년 9월 1일 출시한 B2B 대화형 AI 에이전트 네오나 에이전트로 기업용 시장 진입을 본격화했다.

  4. 4

    2026년 11월 한국방송광고진흥공사의 광고창작 서비스 아이작에 타입캐스트 API가 연동되며 공공 레퍼런스가 추가됐다.

  5. 5

    현재가 4,830원은 공모가 10,000원을 밑돌며, 상장 직후 유통 가능 물량은 상장 예정 주식의 28.66%에 그쳤다.

02

사업 구조

네오사피엔스는 2017년 설립된 AI 음성 생성 기업으로, 자체 음성 생성 파운데이션 모델 SSFM을 기반으로 음성 합성 서비스 타입캐스트를 운영한다. 타입캐스트는 700개 이상의 AI 음성 캐릭터와 37개 언어를 지원하며 누적 가입자는 320만명에 달한다. 사업은 크게 세 축으로 나뉜다.

첫째 축은 개인 창작자가 주로 이용하는 구독형 서비스이며, 회사는 이 기반을 바탕으로 기업용 시장으로 적용처를 넓히고 있다. 둘째 축은 타입캐스트 API로, 영상 제작을 자동화하는 창작자와 코딩 도구를 통한 API 연동이 늘면서 2026년 9월 말 기준 유료 구독자가 전년 동월 대비 152배가 됐다.

셋째 축은 2026년 9월 1일 출시한 B2B 대화형 AI 에이전트 네오나 에이전트로, 음성 인식과 답변 생성, 음성 합성을 자체 기술로 묶은 제품이다. 부문별 매출 비중은 별도로 공개되지 않아 사업별 규모를 직접 비교하기 어렵다.

2026년 반기 해외 매출 비중은 7.02%로 국내 매출이 대부분을 차지하며, B2B API 상위 5곳의 비중은 67%로 보도됐다. 공공 부문에서는 2026년 11월 한국방송광고진흥공사의 광고창작 서비스 아이작에 타입캐스트 API가 연동됐다.

경쟁 측면에서는 AI 음성과 콘텐츠 제작 분야의 여러 기업과 맞서고 있으며, 회사는 감정 표현과 실시간 응답 속도를 차별화 요소로 내세운다.

03

최근 동향

2026년 3분기 누적 공시 기준 매출액은 29.1억원으로 전년 같은 기간 대비 0.4% 감소했다. 같은 기간 영업손실은 18억원, 당기순손실은 15.7억원으로 적자가 이어졌고 손실 규모는 전년 같은 기간보다 확대됐다.

타입캐스트 API 사용량이 빠르게 늘었음에도 공시 매출은 제자리에 머무는 구조가 나타났다. 회사 측은 API 매출이 고객이 크레딧을 실제로 사용하는 시점에 인식된다고 설명하고 있다.

2025년 연결 기준으로 보도된 매출액은 106억 4,900만원이며, 영업손실은 26억 7,600만원, 당기순손실은 69억 9,400만원이었다. 2025년 매출은 전년 대비 66% 이상 증가했고 영업손실은 약 79억원에서 27억원 수준으로 줄었다.

당기순손실에는 전환권조정 상각과 파생상품 평가손실처럼 현금 유출이 없는 회계상 손실이 함께 반영됐다. 2026년 1분기에는 상환전환우선주가 전량 보통주로 전환되면서 자본총계가 마이너스에서 플러스로 바뀌었고, 유동비율은 287.18%로 높아졌다.

주가는 2026년 9월 21일 상장 첫날 장중 33,500원까지 올랐으나 이후 공모가 10,000원을 밑도는 흐름으로 바뀌었다. 2026년 11월 6일 종가는 5,340원으로 전일 대비 4.64% 하락했다. 2026년 11월 18일 14시 23분 기준 현재가는 4,830원이며, 거래대금은 4억원 수준이다.

04

전망

향후 확인할 지점은 API 사용량 증가가 공시 매출로 얼마나 전환되는지다. 회사는 API 매출이 크레딧 사용 시점에 인식되는 구조라 성장세가 앞으로 실적에 더 뚜렷하게 나타날 것으로 보고 있으나, 절대 매출 규모는 아직 공개되지 않았다.

상장 전 보도에 따르면 회사가 제시한 2026년 연간 추정치는 매출 141억원, 영업손실 24억원이다. 이 추정치는 2026년 3분기 누적 매출 29.1억원과 비교하면 4분기에 매출이 크게 몰려야 달성 가능한 수준이어서, 2026년 4분기 실적과 연간 확정 공시가 다음 점검 지점이 된다.

같은 추정에서 2027년은 매출 254억원과 영업이익 33억원으로 흑자 전환하는 것으로 제시됐다. 자금 사용처는 향후 4년간 연구개발 151억원, GPU 인프라 63억원, 신규·해외 사업 59억원으로 계획돼 있다.

제품 측면에서는 네오나 에이전트가 교육 분야에서 고객 상담과 영업 등 기업 업무로 적용 범위를 넓힐 계획이며, 응답 지연 시간을 0.6초에서 0.3초 수준으로 줄이는 것을 목표로 한다.

주식 측면에서는 상장 직후 유통 가능 물량이 28.66%에 그쳤고, 대표 등 4인이 보유 지분 37.68%를 3년간 의무보유하기로 해 해당 물량은 의무보유 기간이 끝나야 유통된다. 따라서 거래 흐름은 공시 실적과 함께 살펴볼 변수다.

05

강세 요인

API 유료 구독자 급증

타입캐스트 API 유료 구독자는 2026년 9월 말 기준 전년 동월 대비 152배로 늘었고, 같은 기간 월간 사용량은 160배, 전체 사용자 수는 63배 증가했다. 3분기 유료 구독자는 직전 분기 대비 5.7배로 증가 폭이 커졌다.

회사는 AI 기반 영상 제작 자동화와 코딩 도구를 통한 API 연동 확산을 주요 요인으로 꼽았다. 다만 이 지표들은 회사가 발표한 수치이며, 절대 API 매출 규모는 공개되지 않았다.

공공·방송 레퍼런스 확대

2026년 11월 12일 한국방송광고진흥공사의 광고창작 서비스 아이작에 타입캐스트 AI 목소리가 공급됐다. 회사는 홈쇼핑, 방송, 교육 등 여러 분야의 기업 고객 수천 곳이 타입캐스트를 이미 쓰고 있다고 밝혔다. 이번 공급은 검증된 기술을 공공 서비스로 확장한 사례로 볼 수 있다는 평가가 나온다. 계약 규모와 반복 매출 비중은 공개되지 않았다.

재무구조 정상화 흐름

2026년 1분기에 상환전환우선주가 전량 보통주로 전환되면서 자본총계가 약 167억원으로 돌아섰고, 유동비율은 36.96%에서 287.18%로 높아졌다. 회사는 결손금 보전 작업을 병행해 상장 이후 배당가능이익을 확보할 기반을 마련했다고 설명했다.

공모 자금 가운데 연구개발에 151억원, GPU 인프라에 63억원이 배정돼 AI 에이전트 기술 투자 여력이 늘어난 것으로 풀이된다.

06

약세 요인

누적 적자와 매출 정체

2026년 3분기 누적 매출액은 29.1억원으로 전년 같은 기간 대비 0.4% 감소했고, 영업손실 18억원과 당기순손실 15.7억원 모두 전년 같은 기간보다 손실이 확대됐다. 2025년 연결 기준으로도 영업손실 26억 7,600만원, 당기순손실 69억 9,400만원으로 적자 구조가 이어졌다. 사용량 지표의 급증이 공시 매출 성장으로 연결되지 않는 점이 가장 큰 약세 요인이다.

연간 추정치 대비 낮은 매출 기저

상장 전 보도에 따르면 회사가 제시한 2026년 매출 추정치는 141억원, 영업손실 추정치는 24억원이다. 2026년 3분기 누적 매출 29.1억원은 이 추정치와 비교할 때 4분기에 매출이 크게 몰려야 달성 가능한 수준이다. 2027년 흑자 전환 추정도 매출 254억원을 전제로 하고 있어 성장 가정이 실현되는지가 관건이다.

좁은 유통 물량과 주가 변동성

상장 직후 유통 가능 물량은 349만 5,095주로 상장 예정 주식의 28.66%였다. 대표 등 4인은 공모 후 보유 지분 37.68%를 3년간 의무보유하기로 했다.

상장 첫날 장중 33,500원까지 올랐던 주가는 2026년 11월 6일 종가 5,340원을 거쳐 현재가 4,830원으로 낮아졌고, 거래대금은 4억원 수준이다.

07

리스크 요인

거시 리스크

금리 환경과 코스닥 성장주에 대한 투자 심리가 바뀌면 상장 초기 주가의 변동성이 커질 수 있다. 회사는 연구개발과 GPU 인프라에 자금을 쓰는 계획이어서 자본시장 여건이 향후 투자 속도에 영향을 줄 수 있다. 신규 상장 기업은 시장 전반의 위험 선호에 민감하게 반응하는 경향이 있다.

고객 집중·수익 구조

B2B API 상위 5곳의 비중이 67%로 보도되어 소수 고객에 대한 의존도가 높은 편이다. 2026년 반기 해외 매출 비중은 7.02%에 그쳐 해외 성장의 기여는 아직 작다. API 매출이 크레딧 사용 시점에 인식되는 구조여서 사용량 증가가 분기 실적에 반영되는 데 시차가 생길 수 있다.

기술·규제

AI 음성 합성 기술은 목소리 복제의 악용 우려 때문에 규제가 강화될 가능성이 있다. 대형 플랫폼과 생성형 AI 기업이 음성 기능을 자체 제품에 통합하면 가격과 점유율 경쟁이 심화될 수 있다.

회사는 음성 인식부터 음성 합성까지 자체 기술로 운영한다고 밝혔으나, 기술 격차가 유지되는지가 변수로 남아 있다.

08

종합 의견

네오사피엔스의 현재 구도는 사업 지표의 빠른 성장과 공시 재무의 적자 지속이 함께 존재하는 상태로 요약된다. 강세 측면에서는 타입캐스트 API 유료 구독자와 사용량이 큰 폭으로 늘었고, 공공기관 공급과 B2B 에이전트 출시로 수요처가 넓어지고 있다.

자본잠식 해소와 유동비율 개선은 재무 안정성 측면의 긍정 요인이다. 반면 2026년 3분기 누적 매출은 전년 같은 기간 대비 0.4% 감소했고, 영업손실과 당기순손실은 모두 확대됐다. 사용량 지표가 공시 매출로 얼마나 이어질지는 2026년 4분기 및 연간 실적에서 드러날 부분이다.

주가는 공모가를 밑도는 수준이며 유통 주식 비중이 작아 거래 변동성이 큰 구간으로 볼 수 있다. 이 내용은 정보 제공 목적의 정성적 요약이다.
